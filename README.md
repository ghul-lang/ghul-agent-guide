# ghūl agent guide

Instructions for a coding agent working on the
[ghul-lang](https://github.com/ghul-lang) repositories. Open this repository as
the editor's root folder and clone the repositories to work on beneath it.
[`AGENTS.md`](AGENTS.md) is the entry point; `CLAUDE.md` and
`.github/copilot-instructions.md` point agents at it.
